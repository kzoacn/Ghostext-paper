**Concrete issues found and addressed.** A budget curve must evaluate each endpoint using the prefix that existed at that endpoint. A failure after N cannot invalidate an already completed N-token observation. The existing `upstream_rrc_experiment.py:222` helper rejects all prefixes when the full stream is non-complete and expects natural-sampler-only metadata. Reusing it for the 2N stream would make shorter-budget outcomes depend on a future failure. The amended plan correctly requires each reached endpoint to be finalized and persisted before continuing, preserves those prefixes after later failure, and treats only unreached endpoints as generation failures. The separate budget runner still needs to implement this rule.

The auxiliary “retokenized continuation length” was initially undefined on a prompt-prefix mismatch, and the character-length convention and score orientation were not fully fixed. The amended plan uses the full published string's token count and Unicode code-point count, always with higher meaning positive, and zero for the no-output observation. These are total public functions and do not require removing mismatch cases.

**What the follow-up addresses.** The primary score is now defined on every complete published string, including changed tokenization and failed message recovery. Its negative-infinity outcomes are public decisions rather than eligibility filters. This directly addresses the canonical-pair selection limitation, provided every planned arm/control generation completes or the stated no-output distinction is maintained. It is legitimate to use this as a heuristic public distinguisher without claiming it equals the probability of a rendered string. The GPT-2 extension is correctly labelled retrospective because its earlier test outcomes have been inspected.

Qwen2.5-0.5B supplies a different model/tokenizer realization of the unchanged RRC core. Reusing the same prompts and experimental tapes makes this a paired model replication; it adds no independent prompt clusters. The plan explicitly preserves that limitation and does not extend the Markov theorem. The endpoint multipliers are independent of the evaluated stream's own content, and no endpoint is chosen because recovery succeeds. Thus the curve can measure the recovery/rate tradeoff without selecting successful prefixes. A natural control is unnecessary for that recovery-only question.

**Implementation and interpretation cautions.** These do not require new experiments or a different design:

- Keep scorer inputs and cache keys entirely public. Cache identity must include the model/tokenizer/source configuration, prompt, B, and complete string. Test infinity ties and a negative-infinity development quantile explicitly; infrastructure exceptions must remain distinct from defined public failure statuses.
- If no-output cases occur, retain the augmented all-attempt analysis separately. An emitted-string summary should keep every emitted string with class-specific denominators; requiring its paired counterpart to emit would introduce another selection rule. Passive text observers do not observe unsent attempts.
- Bootstrap whole prompt clusters with all their paired budget outcomes. Recovery-gain intervals should preserve the same trajectories across endpoints. State whether TPR/FPR intervals condition on the fitted development threshold. Higher precision at 2N can change the old N-token numerical path; the plan appropriately makes the new, consistently configured stream primary and retains discrepancies. Recovery need not be forced to look monotone.
- Preserve the exact upstream core when claiming unchanged-code replication. Harness/configuration changes are compatible with that claim; edits to pinned sender, receiver, or stepper functions would require a different label. Record effective vocabulary and dtype: local Qwen metadata has 151,936 model output dimensions and 151,665 contiguous tokenizer-supported IDs, while the plan deliberately specifies float32 inference.

The all-text analysis will not, by itself, establish residual leakage after matching observable lengths. Reporting two length-score AUCs is useful but does not prove equality of their full distributions. The plan correctly avoids that claim. Known prompts and payload sizes, ten held-out prompt clusters, the absence of a low-FPR deployment calibration, and the ideal theorem's restricted source assumptions remain material limits after these follow-ups.
