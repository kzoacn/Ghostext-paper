\title{Ghostext: Auditing Finite-Message Leakage in LLM Steganography}
\author{}

\begin{document}

\maketitle

\begin{abstract}
Language-model steganography often evaluates security through next-token
probabilities, although an observer receives a finite text with an endpoint.
We study three ways in which these objects differ: deterministic padding of
finite input bits, rounding inside a shrinking integer interval, and
content-dependent termination. Executing the original Neural Linguistic
Steganography encoder on an exhaustive synthetic example yields terminal-token
total variation $15/16$ while its reported average KL is zero. For the published
rotation range-coding algorithm, we derive a public stopping likelihood and
an exact counterexample even when the natural control has the same marginal
length distribution. On every fixed nonuniform binary IID source, the distance
between these two stopped-text laws tends to one as message length grows.
We then implement a guarded-prefix repair in Ghostext, retaining authenticated
packet recovery while bounding integer-coding error against an explicitly
specified stopping-matched reference. An audit of archived Qwen outputs
and fresh authenticated-delivery trials test a password-free bootstrap probe.
In controlled GPT-2 and bilingual Qwen stopping experiments, 386 of 480
attempted pairs yield complete, canonical, length-matched outputs. A public
surprisal score achieves held-out AUCs of 0.865--0.973 within these eligible
slices, while length alone has AUC 0.5. All failed attempts remain recorded.
These results separate codec
correctness, conditional sampling accuracy, and complete-text security;
the guarded codec alone does not establish indistinguishability from ordinary
language-model generation.
\end{abstract}
