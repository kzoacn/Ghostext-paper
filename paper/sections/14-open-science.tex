\section{Open Science}
\label{sec:open-science}

This statement describes the artifact supporting the IEEE S\&P 2027 draft.

\paragraph{Anonymous artifact for review}
The review artifact includes the protocol implementation, exact-audit and
measurement scripts, retained observations, and manuscript sources. Its export
removes author-identifying host and path metadata while preserving observation
fields, and records original-to-exported file hashes. The working repositories
are separate from this review package.

\paragraph{Reproducibility metadata}
Each cohort has a source profile, model hashes, task list, and configuration.
Content-addressed snapshots preserve manifest-listed source versions;
omitted helper modules are separately pinned and compatibility-checked.
A command index specifies entry points, required data inputs, and stopping caps. A separate
environment snapshot supplements package fields missing from older delivery
manifests. Model acquisition uses exact upstream revisions, including the
historical Qwen GGUF whose current upstream replacement has different bytes.

\paragraph{Scope of reproducibility claim}
Saved-data analyses and exact checks need no model weights. Public-feature
replays and fresh generation use separately downloaded models. Stopping-study
random tapes are repeatable on the compatible stack; authenticated delivery
uses OS randomness and is statistically rerunnable, with saved text available
for replay. Cross-hardware bit-level determinism is not claimed.
