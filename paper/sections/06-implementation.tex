\section{Implementation and Reproducible Measurement}
\label{sec:implementation}

The implementation separates packet crypto, candidate policy, quantization,
integer codec, model backend, and the encode/decode pipeline. The guarded codec
uses arbitrary-precision Python integers and operating-system randomness for
its suffixes. An explicit zero-guard option retains the legacy codec for
controlled comparisons. Protocol tests cover integer invertibility, bilingual
text recovery, wrong credentials and mismatched settings, empty messages, and
failure on impossible token paths. Exhaustive tests additionally verify the
uniform-64 support counterexample and recovery for every byte under
context-dependent candidate tables.

\paragraph{Observation without changing the wire format.}
An optional attempt callback records success or failure, elapsed time, packet
hash and length, and the generated prefix for every encoding attempt. Normal
library use emits none of this telemetry. Research scripts preserve failed
attempts instead of retaining only the final cover. A separate keyless probe
accepts text, public configuration, and bootstrap length; its interface does not
accept a passphrase. It records distinct rejection reasons and can be replayed
on natural controls.

\paragraph{Model environments.}
The archived measurements use Qwen3.5-2B, a third-party Q4\_K\_S GGUF, and
\texttt{llama-cpp-python} 0.3.20 with packaged llama.cpp build
\texttt{f49e917}. The fresh experiments also use a local GPT-2 adapter through
Transformers, with raw continuation prompts rather than Qwen's chat template.
Weight files, tokenizer files, source modules, and execution parameters are
hashed in each fresh run manifest. These are CPU experiments; cross-hardware
bitwise replay is not claimed.

\paragraph{Independent checks.}
The exact codec experiment enumerates both complete coded paths and invalid
reference branches using rational arithmetic. Its reference law is recomputed
from token frequencies rather than inferred from the encoder's reported KL.
The NLS harness fetches a pinned original revision and executes selected
function definitions unchanged, with synthetic logits supplied by a small
model stub. The RRC one-bit example independently enumerates its stopped law
and every string in the length-matched control. These checks address different
assumptions from ordinary round-trip tests.

\paragraph{Stopping experiments.}
Our real-model RRC adapter implements the published rotation and midpoint rule
with rational arithmetic and 192-bit pseudorandom rotation draws. It operates
over the same explicitly masked, truncated, stable, quantized source $Q$ used
by its natural control. This is a controlled algorithm study, not a reproduction
of the publication's original model setup. Later verification-before-stop code
is not silently substituted for the published rule. Each record retains the
visible text, token IDs, selected probabilities, stopping status, canonical
retokenization check, and reverse-recovery result. Public seeds are for
repeatability; the evaluation does not claim cryptographic secrecy of test data.

\paragraph{Failure and resume discipline.}
Experiments save each completed record before starting the next case. Resuming
requires matching source and model hashes and the complete configuration.
Source or parameter changes require a new result directory. An interrupted run,
a single smoke test, and a completed evaluation cohort are kept distinct.
All comparisons must state whether they concern attempted generation,
successful delivery, or conditioning on successful matched pairs.
