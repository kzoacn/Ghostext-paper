\section{Implementation and Measurement}
\label{sec:implementation}

Ghostext separates packet crypto, candidate policy, quantization, integer codec,
model backend, and the encode/decode pipeline. The guarded codec uses Python
integers and operating-system suffix randomness. An explicit zero-guard option
retains the legacy codec. Tests cover bilingual recovery, wrong credentials,
configuration mismatch, impossible paths, empty messages, and exhaustive
one-byte recovery under context-dependent tables. An optional callback records
every completed encoding attempt, including failed prefixes, packet hashes,
and elapsed time; normal library use emits none of this telemetry.

\paragraph{Model and numerical environments}
The experiments use GPT-2~\cite{radford2019gpt2} and base
Qwen2.5-0.5B~\cite{qwen2024models} through Transformers, plus Qwen3.5-2B in a
third-party Q4\_K\_S GGUF through \texttt{llama-cpp-python} 0.3.20, packaged
llama.cpp build \texttt{f49e917}. The host has an AMD Ryzen 7 7800X3D CPU and
31\,GiB RAM. Original controlled stopping runs use two GPT-2 and four
Qwen3.5 inference threads; authenticated delivery and its final replays use
two. The upstream RRC studies use float32 weights and one CPU inference
thread per worker. Source and model bytes,
parameters, task lists, and CPU allocations are recorded; cross-hardware
bitwise replay is not claimed. Instrumented delivery decoding repeats candidate
auditing, so its latency is not a production benchmark.

\paragraph{Distinct executed algorithms}
The original controlled RRC adapter uses rational arithmetic, 192-bit
pseudorandom rotations, and Ghostext's explicitly processed integer source
$Q$. Its $2B$-token cap follows the April implementation's harness. Its logged
reverse check reuses sender intervals and offsets. The later upstream study
instead executes pinned, unchanged sender and receiver functions with their
full-vocabulary source, Decimal arithmetic, nominal 53-bit rotations, and
independently initialized receiver steppers. The two experiments therefore
test different numerical and source conditions. Appendix~\ref{app:rotation-grid}
only bounds the former unverified public token/stop process under independent
uniform grid draws. Public experimental PRNG tapes are not cryptographic keys.

\paragraph{Independent observations and persistence}
Exact audits recompute path laws independently of reported KL. Keyless replay
functions take visible text and public parameters; saved IDs, intervals, and
packet hashes are used only afterward for fidelity checks. Cohorts retain
source failures, serialization changes, and recovery failures. Resuming a run
requires its frozen sources and matching manifest; completed observations are
not replaced. Upstream experiments persist every variant and receiver stage
before advancing. Saved-data analyses state whether they use all attempts,
canonical matched outputs, or successful deliveries.
